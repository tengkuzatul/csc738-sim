    Logistic Regression

    • Adds up the features with weights to get a score.
    • The sigmoid turns the score into a probability between 0 and 1.
    • Predict class 1 when the probability is at least the threshold (usually 0.5).
    • Draws a straight boundary; scale the features; tune C.

    2

    Naïve Bayes

    • Uses Bayes' rule to find the most probable class.
    • Multiplies the probability of each feature given each class.
    • "Naïve": assumes features are independent given the class.
    • Very fast; a strong baseline for text (Multinomial variant).

    3

    K-Nearest Neighbours

    • Find the k training points closest to the new point.
    • Predict the majority class among them.
    • Small k follows noise (overfits); large k is too smooth (underfits).
    • Uses distances, so always scale the features.

    Back in the explorer at the top: choose KNN, set the noise to high and k = 1, and compare training and test accuracy. Then try k = 15.

    4

    Support Vector Machine

    • Chooses the boundary with the widest margin between the classes.
    • Support vectors are the points closest to the boundary.
    • C controls how many points may sit inside the margin.
    • Kernels (e.g. RBF, with gamma) allow curved boundaries.

    Try it: what C does to the margin

    An illustration, not a trained model: smaller C allows a wider margin with more points inside it; larger C squeezes the margin to avoid them.

    5

    Decision Trees

    • Asks a series of yes/no questions on the features.
    • Each split makes the groups as pure as possible (Gini or entropy).
    • Easy to explain; no scaling needed.
    • A deep tree overfits: limit max_depth.

    6

    Random Forest

    • Each tree learns from a random bootstrap sample of the rows.
    • Each split looks at a random subset of features.
    • All trees vote; the majority wins.
    • Mainly reduces variance (overfitting); gives feature importance.

    Try it: why voting helps

    Each of 25 trees is right 65% of the time, on its own. Press the button to let them vote on 200 new cases.

    7

    Boosting: AdaBoost, Gradient Boosting, XGBoost

    • Trains trees one after another.
    • AdaBoost gives more weight to the samples previous trees got wrong.
    • Gradient Boosting fits each new tree to the remaining errors.
    • Mainly reduces bias; lower learning_rate needs more trees.

    Bagging

    Many trees in parallel, each on a random sample, then a vote. Like asking many independent experts.

    Boosting

    Trees in sequence, each fixing the last one's mistakes. Like a team where each member corrects the one before.

    Choosing a classifier

    No algorithm wins everywhere. Start with a majority-class baseline, then compare several models with stratified cross-validation and report the mean ± standard deviation.
